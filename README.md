# Hand Dodge Game

A browser-based JavaScript game controlled by real-time hand tracking through webcam.
MediaPipe Hands was used to detect the user's index finger position and use it to control the character on an HTML canvas. 

## Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas API
- MediaPipe Hands
- MediaPipe Camera Utils

## Features

- Real-time webcam hand tracking
- Index finger-controlled player movement
- Falling obstacle gameplay
- Score and lives system
- Collision detection
- Game over and restart functionality
- Keywrods controls as an alternative input

## How To Play

Allow webcam access and move your index finger right/left to control the character. Dodge the falling obstacles to increase your score. Press 'R' to restart the game.
